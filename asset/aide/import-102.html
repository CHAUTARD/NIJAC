Où trouver le fichier 102 sur le site FFTT ?

  1. Se connecter au SPID FFTT
    Rendez-vous sur spid.fftt.com et connectez-vous avec vos identifiants.
  2. Menu Licenciés → Éditions
    Dans le menu de gauche Licenciés, cliquez sur Éditions.
  3. Choisir l'édition « 102 »
    Dans la liste des éditions, sélectionnez 102 - Liste des arbitres et juges-arbitres, puis renseignez :
    • Organismes : L09 - NORMANDIE
    • Grade : Juge Arbitre par Équipe (JA1)
    • Inactivité : Oui (pour importer aussi les JA inactifs et réactiver ceux redevenus actifs)
    • Format : CSV
  4. Générer et sauvegarder
    Cliquez sur Générer, puis enregistrez le fichier sur votre poste.
  5. Importer le fichier
    Cliquez sur le bouton ci-dessous et sélectionnez le fichier téléchargé.
  6. Valider
    Choisir le fichier .txt local.
