# NIJAC – Répertoire des écrans

La colonne **Menu** indique d'où l'écran est atteint : `E002` = menu paramètres administrateur, `E020` = menu nominateur, `E034` = menu CSR, `E038` = menu défiscalisateur. « Public » = page tokenisée sans menu (lien envoyé par email / généré par un autre écran).
