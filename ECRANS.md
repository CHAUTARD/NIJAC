# NIJAC – Répertoire des écrans

La colonne **Menu** indique d'où l'écran est atteint : `E002` = menu paramètres administrateur, `E003` = menu nominateur, `E004` = menu CSR, `E005` = menu défiscalisateur. « Public » = page tokenisée sans menu (lien envoyé par email / généré par un autre écran).

Numérotation par bande de menu : E001-E010 = connexion + menus · EN11-EN30 = nominateur + pages publiques/JA · ES31-ES50 = CSR · ED51-ED70 = défiscalisateur · EA80+ = paramétrage administrateur.
