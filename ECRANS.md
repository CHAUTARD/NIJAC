# NIJAC – Répertoire des écrans

+------+-----------------------------------+---------------------------------+-----------------|
|  N°  |          Titre                    |           Fichier               | Fonctionnalités |
|------|-----------------------------------|---------------------------------|-----------------|
| E001 | Page de connexion                 | `index.php`                     | Saisie login / mot de passe · Afficher/masquer le mot de passe · Vérification des identifiants en base · Redirection selon le rôle (Admin → E002, Nominateur → E020) · Forçage du changement de mot de passe à la première connexion |
| E002 | Menu paramètres administrateur    | `admin_menu.php`                | Accès aux écrans de paramétrage (E005 à E017) · Bascule vers le menu nominateur (E020) · Alerte changement de mot de passe en attente |
| E005 | Gestion des salles                | `salle.php`                     | Liste des salles de compétition · Création / modification / suppression · Rattachement à un club · Désignation de la salle principale · Coordonnées GPS issues de la table laposte |
| E006 | Gestion des communes              | `communes.php`                  | Référentiel codes postaux / communes (table laposte) · Coordonnées GPS (latitude / longitude) · Utilisé pour les calculs de distance domicile-salle lors des nominations |
| E007 | Gestion des Juges-Arbitres        | `Nominateur/jugearbitre.php`    | Import depuis fichier Excel FFTT · Liste des JA avec grade et coordonnées · Activation / désactivation d'un JA · Normalisation automatique des villes via la table laposte · Modification des fiches JA |
| E008 | Gestion des clubs et associations | `club.php`                      | Import depuis fichier Excel FFTT (upsert) · Liste des clubs affiliés · Création / modification · Champs : N° FFTT, nom du club · Coordonnées correspondant (nom, email, téléphone) · Synchronisation depuis l'API FFTT |
| E009 | Gestion des utilisateurs          | `utilisateur.php`               | Création / modification / suppression de comptes · Rôles : Administrateur ou Nominateur · Affectation d'un département · Activation / désactivation · Forçage du changement de mot de passe |
| E010 | Gestion des divisions             | `division.php`                  | Définition des divisions sportives et de leur niveau hiérarchique · Utilisé pour classer les rencontres et orienter les règles de nomination |
| E011 | Import des rencontres             | `ImportRencontresController` (CI4) | Import direct depuis l'API FFTT (Ligue → Épreuve → Division → Poules → Rencontres) · Alimentation de la table rencontre (upsert) · Désignation directe des arbitres R3M/R4M |
| E012 | Régions                           | `region.php`                    | CRUD des régions (code, nom, gentilé, chef-lieu) · Utilisé pour la configuration régionale de l'application |
| E013 | Départements                      | `departement.php`               | CRUD des départements (code, nom, région) · Liaison FK vers la table region |
| E015 | Configuration générale            | `configuration.php`             | Paramètres applicatifs stockés dans la table `configuration` · État du logiciel : Opérationnel / Développement · En mode Développement, tous les emails sont redirigés vers l'adresse de test |
| E016 | Nettoyage / Saison                | `clean.php`                     | Sauvegarde SQL de la saison (fichier dans `/SQL/`) · Désactivation des JA (Actif = 0) · Vidage des tables Disponible, Equipe, Rencontre, Nomination · Restauration depuis un fichier de sauvegarde avec confirmation par mot de passe admin |
| E017 | Import Rencontres Nationales      | `import_rencontres_nat.php`     | Deux onglets : import via l'API FFTT (scan des clubs de la région, chargement des équipes nationales), ou import d'un fichier Excel FFTT à plusieurs feuilles (N1M, N2M, N3M, N1F, N2F) déposé dans `Importation/Rencontres/Nationale/` · Les deux alimentent la même table `equipe_nationale` et partagent la section d'association équipe → club/département |
| E018 | Test API FFTT                     | `fftt_test.php`                 | Interface de diagnostic de l'API FFTT (Smartping v2) réservée à CHAUTARD · Appel manuel de chaque endpoint (clubs, licenciés, équipes, épreuves, divisions, poules, rencontres) · Lecture seule, aucune écriture en base |
| E020 | Menu nominateur                   | `Nominateur/menu.php`           | Tableau de bord : JA actifs, nominations à valider, convocations à envoyer, rencontres sans JA, prochaine journée · Badges d'alerte sur les boutons · Accès aux fonctions de nomination (E021 à E026, E028) · Bascule vers le menu admin |
| E021 | Saisie des disponibilités JA      | `Nominateur/disponibilites.php` | Consultation des disponibilités par département · Sélection du département (14, 27, 50, 61, 76 — le 76 inclut automatiquement le 27) · Ouverture de la fiche de disponibilité d'un JA par journée dans une fenêtre dédiée |
| E022 | Nomination des Juges-Arbitres     | `Nominateur/nomination.php`     | Affectation des JA aux rencontres · Application des règles métier : exclusion si le club du JA joue, max 2 rencontres du même club par phase, 1 seule rencontre par date · Priorité aux rencontres choisies par le JA dans ses disponibilités · Sélection de la rencontre la plus proche du domicile · Priorité au JA ayant le moins d'arbitrages · Attribution automatique d'une 2ᵉ rencontre dans la même salle · Validation des nominations |
| E023 | Désidératas club                  | `Nominateur/desiderata_club.php`| Page publique tokenisée (lien `?club=<Id_Club>`) remplaçant le questionnaire Excel envoyé aux clubs · Saisie correspondant, salle (nom, adresse, téléphone, nb d'aires de jeu) et désidératas par équipe (Pré-Nationale à R4M) : réengagement, jour de rencontre souhaité, souhait de désignation JA (CRA/Club) pour les équipes R3M/R4M · Le souhait JA met à jour `equipe.JAdemande` et `rencontre.ArbitrageObligatoire` · Zone de note libre pour signaler toute modification · Lien envoyé depuis E027 |
| E024 | Centre d'envoi                    | `Nominateur/centrenvoye.php`    | Envoi des 4 types de messages aux JA actifs du département · Convocations, rappels, annulations, informations générales · Suivi des emails envoyés / en attente |
| E025 | Comptabilité frais JA             | `Nominateur/compta.php`         | Récapitulatif des frais de déplacement des JA pour une période · Export CSV au format EBP (journal AC) |
| E026 | Gestion des messages              | `Nominateur/messagerie.php`     | Création et gestion des modèles de messages · Types : convocation, rappel, annulation, information · Champs : sujet, corps du message · Association à un utilisateur |
| E027 | Désidératas clubs                 | `Nominateur/JA_R3R4.php`        | Liste des clubs ayant des équipes Pré-Nationale à R4M avec case à cocher · Boutons Tout sélectionner / Tout désélectionner · Envoi groupé du questionnaire de désidératas (message système n°6, lien vers E023) aux correspondants des clubs sélectionnés · Statut Soumis / En attente selon la saison en cours, date du dernier envoi · Accès rôle CSR ou Administrateur (filtre "csrauth"), plus accessible au Nominateur — lien depuis le menu CSR (E034) |
| E028 | Statistiques JA                   | `Nominateur/stats_ja.php`       | Tableau arbitrages / km / péages / indemnités / total frais par JA · Filtres période (date début–fin) · Tri par colonne · Export CSV · Impression | Signalement des équipes R3 / R4 demandant un JA · Activation du flag `JAdemande` → toutes les rencontres à domicile passent en `ArbitrageObligatoire = 1` |
| E029 | Adresse domicile JA               | `Nominateur/adresse_ja.php`     | Page publique tokenisée permettant à un JA de renseigner ou corriger son code postal et sa ville à partir de la table laposte · Lien généré depuis E007 · Suggestions de communes en cas de CP ambigu · Enregistrement dans `ja.Cp`, `ja.Ville`, `ja.Id_LaPoste` |
| E030 | Fiche personnelle JA              | `JA/info_rencontre.php`         | Page publique tokenisée (`?ja=TOKEN`), au même titre que E029/E031/E032 — plus de rôle JA ni de login dédié · Affiche la fiche identité (grade, club, coordonnées) et les nominations à venir · Pour les clubs en arbitrage club (`SouhaitJA='Club'`), sélection multiple par case à cocher des rencontres R3M/R4M à domicile à arbitrer, validation groupée |
| E031 | Convocation et frais JA           | `Nominateur/convocation_ja.php` | Page publique (URL `?nomination=<Id_Nomination>` en clair, sans obfuscation) affichant la convocation officielle imprimable d'un JA pour une rencontre · Saisie des frais (péages, kilomètres, rapport d'accueil/équipements) · Calcul du total (indemnité forfaitaire + péages + km × tarif) · Lien généré depuis E022 (envoi des convocations) |
| E032 | Disponibilité JA                  | `Nominateur/disponibilite_ja.php` | Page publique (`?ja=TOKEN` obfusqué ou `?id_ja=N`) permettant à un JA de déclarer ses disponibilités par journée (Disponible / Partiel / Non disponible), avec sélection fine des rencontres en mode Partiel · Vue calendrier mensuel et liste de journées · Distance domicile-salle (Haversine) · Note libre et case défiscalisation · Lien généré depuis E007 (action "token") ou utilisé directement depuis E021 |
| E033 | Changement du mot de passe         | `changer_mot_de_passe.php`      | Ouverte depuis la modale "Mot de passe à modifier" du bandeau utilisateur (toolbar), en AJAX (modale Bootstrap) ou en page complète si JS désactivé · Vérification du mot de passe actuel, saisie et confirmation du nouveau (8 caractères minimum) · Mise à jour du hash et réinitialisation du flag ChangeLogin · Accessible à tout utilisateur authentifié (Administrateur ou Nominateur), pas au rôle JA |
| E034 | Menu CSR                          | `csr_menu_index.php`            | Tableau de bord minimal du rôle CSR (Commission Sportive Régionale) : 3 cartes (Club CSR E035, Messagerie E026, Désidératas clubs E027) · Accès rôle CSR ou Administrateur (filtre "csrauth") |
| E035 | Club CSR (envoi email)            | `club_csr_index.php`            | Variante de E008 pour le rôle CSR : même liste de clubs (recherche, tri, filtre département/région, édition Nom/Nom équipe/Correspondant), sans synchronisation FFTT ni filtre "Plusieurs salles" · Case à cocher par ligne, boutons Tout sélectionner/désélectionner · Envoi groupé aux correspondants des clubs cochés du message système n°6 (Réengagements, le même qu'E027), éditable via E026 où le rôle CSR n'a accès qu'à ce message |
| E099 | Administration base de données    | `db-admin.php`                  | Navigation dans les tables (sidebar) · Onglet Données : parcours, recherche, tri, pagination, création / modification / suppression de lignes, 
|      |                                   |                                 | export CSV table entière, vidage TRUNCATE · Onglet Structure : liste des colonnes avec types et contraintes, 
|      |                                   |                                 | ajout / modification / suppression / renommage de colonne, gestion des index (ajout, suppression) · 
|      |                                   |                                 | Onglet Requêteur SQL : exécution libre, export CSV des résultats, support Ctrl+Entrée et indentation Tab · 
|      |                                   |                                 | Accès réservé à l'administrateur CHAUTARD                                                                                                                                                                                      |
